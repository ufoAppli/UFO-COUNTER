# UFO COUNTER

シンプルなスマホ向けWebアプリです。

## 概要
- ローカルストレージに店舗と筐体データを保存します。
- 画像はカメラ撮影またはファイル選択で保存できます。
- データ閲覧画面から店舗ごとの集計、CSV出力が可能です。
- サービスワーカーを使ってオフラインでも表示できるようにしています。

## ファイル
- `index.html` - 画面構成
- `styles.css` - スタイル
- `app.js` - アプリの動作
- `manifest.json` - PWA設定
- `sw.js` - オフラインキャッシュ
- `icon-192.png` / `icon-512.png` - アプリアイコン

## 実行方法
1. ローカルにコピーします。
2. `python -m http.server 8000`などでWebサーバーを立ち上げます。
3. ブラウザで `http://localhost:8000/` を開きます。

※ service worker はHTTPSまたはローカルホストでのみ動作します。

## 公開方法
このアプリは静的なWebサイトなので、サーバー側のプログラムは不要です。以下のいずれかの方法で公開できます。

### 1. GitHub Pages を使う
1. GitHubで新しいリポジトリを作成します。
2. このフォルダをGit管理にします。
   - `git init`
   - `git add .`
   - `git commit -m "Initial commit"`
   - `git branch -M main`
   - `git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git`
   - `git push -u origin main`
3. GitHubのリポジトリ設定から「Pages」を開き、ソースを `main` ブランチの `/ (root)` に設定します。
4. 数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

### 2. Netlify / Vercel を使う
1. Netlify または Vercel にアカウントを作成します。
2. GitHubリポジトリを接続するか、アプリのフォルダをドラッグ&ドロップします。
3. ビルド設定は不要です。公開URLが発行されます。

### 3. 自分のWebサーバーで公開する
1. サーバーの公開用ディレクトリにこのフォルダのファイルを配置します。
2. Webサーバー（Apache、nginx、IISなど）で `index.html` がルートで開くよう設定します。

### 限定公開について
- GitHub Pagesは通常公開サイトになります。URLを知っている人だけに共有すれば、実質的には限定公開として使えます。
- より厳密に限定公開したい場合は、パスワード保護できるホスティングや社内サーバーを使う方法をおすすめします。
- ローカルネットワーク内のみで使う場合は、パソコンやNAS上でHTTPサーバーを起動し、同じネットワークのスマホからアクセスします。
